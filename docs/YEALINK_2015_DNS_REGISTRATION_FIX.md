# Yealink 2015: DNS и регистрация — 2026-10-12

## Симптом и диагностика

Yealink T21P_E2 с номером `2015` показывал `Register Failed` для аккаунта на
`phone.awesomeio.ru:5061` с TLS. Телефон получал сеть по DHCP: адрес
`192.168.20.192/24`, шлюз `192.168.20.1`, DNS `192.168.20.1`. Запрос к
локальному DNS для `phone.awesomeio.ru` возвращал `SERVFAIL`; прямые запросы к
публичным резолверам `1.1.1.1` и `8.8.8.8` возвращали адрес edge-сервера
`94.102.89.13`.

## Исправление

В веб-интерфейсе телефона открыли **Network → Basic** и изменили только DNS:

| Параметр | Значение |
| --- | --- |
| IPv4 | DHCP (без изменений) |
| Static DNS | On |
| Primary DNS | `1.1.1.1` |
| Secondary DNS | `8.8.8.8` |
| Адрес / шлюз | DHCP: `192.168.20.192`, `192.168.20.1` |

После **Confirm** телефон перезагрузился для применения сетевых параметров.
Учётные данные SIP, адрес сервера, порт и TLS в рамках этого исправления не
меняли. Пароли в репозитории не хранятся.

## Проверка результата

После перезагрузки страница **Status** телефона показала:

- WAN: DHCP, `192.168.20.192/24`, шлюз `192.168.20.1`;
- Primary/Secondary DNS: `1.1.1.1` и `8.8.8.8`;
- Account 1: `2015@phone.awesomeio.ru : Registered`.

Таким образом подтверждены сохранение DNS и SIP-регистрация телефона. Звонки,
двусторонний звук и PSTN-маршрут этим исправлением не проверялись. Последний
отдельный результат приёмки браузерных звонков остаётся в
[BROWSER_CALL_ACCEPTANCE.md](BROWSER_CALL_ACCEPTANCE.md); новую приёмку в рамках
этой настройки не запускали.

## Повторение настройки

1. Откройте текущий DHCP-адрес телефона и войдите в веб-интерфейс.
2. Перейдите в **Network → Basic**, оставьте IPv4 в режиме DHCP.
3. Включите **Static DNS**, задайте `1.1.1.1` и `8.8.8.8`, нажмите
   **Confirm** и дождитесь перезагрузки.
4. На странице **Status** проверьте шлюз, оба DNS-адреса и статус аккаунта
   `Registered`.

Если DHCP выдаст телефону другой адрес, найдите новый адрес в таблице DHCP-аренд
роутера. Домашние имена, доступные только через локальный DNS роутера, при такой
настройке телефона могут не разрешаться.
