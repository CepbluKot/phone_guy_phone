# Требования к IP-телефону для Phone Guy

Этот список относится к уже работающему приватному Asterisk на VM209.
Заказанный **Yealink SIP-T21P E2 подходит**: он поддерживает SIP, Ethernet,
ручную настройку аккаунта и G.711 A-law. Дальнейшие поля настройки описаны в
[SIP_PHONE_T21P_E2_SETUP.md](SIP_PHONE_T21P_E2_SETUP.md).

## Обязательные требования

Нужен обычный проводной **SIP IP-телефон**, у которого есть:

- стандартный SIP RFC3261, а не только Teams/Zoom или облачная АТС;
- ручная настройка SIP server, логина и пароля;
- Ethernet RJ-45;
- голосовой кодек G.711 A-law; G.722 желателен, но не обязателен;
- доступная web-админка и factory reset;
- микрофон в трубке и динамик трубки/громкой связи;
- питание: штатный блок **или** PoE.

Один SIP-account достаточно. Вторым участником для первого звонка будет
компьютер с softphone и микрофоном, поэтому второй физический телефон не нужен.

## Чек-лист для объявления на Авито

- В описании или на фото есть слова `SIP`, `SIP account`, `SIP server`.
- Телефон включается и получает сеть по Ethernet.
- Продавец подтверждает factory reset.
- После reset доступна web-админка.
- Аппарат не остался привязан к корпоративному provisioning-server.
- Есть блок питания или у тебя есть PoE-свитч/PoE-инжектор.

## Что ещё может понадобиться

### Телефон в домашней сети

Только телефон, Ethernet-кабель и питание. Если у свитча есть PoE — отдельный
адаптер питания обычно не нужен.

### Телефон в другом месте

Телефон сам обычно не умеет WireGuard. Рядом нужен маленький роутер с
WireGuard-клиентом, к которому телефон подключается Ethernet-кабелем. Он
создаёт защищённый маршрут до хомлаба; SIP и RTP не публикуются в интернет.

## Не покупать для первого теста

- телефон только для Microsoft Teams/Zoom;
- GSM-телефон;
- аналоговый телефон без ATA-адаптера;
- DECT-трубку без совместимой базы;
- старую корпоративную Cisco/Avaya без гарантированного factory reset и
  ручной SIP-настройки.

## Отдельный путь для FNaF-телефона

Если цель — встроить электронику внутрь винтажного корпуса, готовый IP-телефон
покупать необязательно. Позже можно поставить Linux-компьютер с микрофоном,
динамиком и SIP-клиентом. Это гибче для корпуса, но сложнее по электронике.
Для проверки самой телефонии сначала проще купить один обычный SIP-телефон.
