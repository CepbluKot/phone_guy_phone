# Phone Line

**Для продолжения RVC-разработки сначала прочитайте [HANDOFF](docs/HANDOFF.md).**
На 2026-09-06 AI-only версия развёрнута и проверена через сайт.
Версия, результаты и откат: [LIVE_STATUS](docs/LIVE_STATUS.md).

Телефон в браузере: https://voice-phone.lan.awesomeio.ru/phone/; админка:
https://voice-admin.lan.awesomeio.ru/admin/ (оба адреса доступны через VPN).
Старый адрес https://voice.lan.awesomeio.ru перенаправляет на новые домены.

В новом интерфейсе: наденьте наушники → нажмите «Начать» → разрешите микрофон →
дождитесь готовности модели → говорите непрерывно. К накоплению и обработке
фрагмента добавляется регулируемая задержка 0–10 с, по умолчанию 5 с. «Остановить»
сразу выключает микрофон и отбрасывает незавершённый последний фрагмент.

В текущем production работает Phone Guy RVC. В UI нет
выбора профиля, DSP-настроек или тестового тона; старый образ сохраняется только
для аварийного отката. Доставка, пятиминутный private-WSS прогон и браузер проверены.
Для неё используется только scoped `deploy/deploy-rvc.sh`, не старый DSP deploy.
Виртуальный микрофон для сторонних приложений не входит в задачу.
