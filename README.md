# Phone Line

**Для продолжения RVC-разработки сначала прочитайте [HANDOFF](docs/HANDOFF.md).**
На 2026-09-06 эта ветка содержит новый AI-режим, но сайт ещё использует старый
DSP-интерфейс. Следующее описание относится к текущему production DSP.

Приватная демка изменения голоса: https://voice.lan.awesomeio.ru через VPN.

Наденьте наушники → «Проверить звук» → «Начать» → разрешите микрофон.
Ползунки применяются на ходу. Код и документы хранятся на ноутбуке,
приложение работает в выделенной VM 209 на сервере.

- [Аудит и проверка](docs/AUDIT_2026-09-06.md)
- [Исходная спецификация](docs/superpowers/specs/2026-09-06-phone-guy-voice-demo-design.md)

В текущем production работает телефонный DSP-эффект с изменением высоты.
RVC-интеграция подготовлена в этой ветке, доставка ещё не завершена.
Для неё используется только scoped `deploy/deploy-rvc.sh`, не старый DSP deploy.
Виртуальный микрофон для сторонних приложений не входит в задачу.
