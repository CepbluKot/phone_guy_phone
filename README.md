# 📞 Phone Guy

Phone Guy — проект для телефонных разговоров через браузер и обычные телефоны,
подключённые к интернету. Для выбранных телефонных номеров система может менять
голос во время разговора, используя голосовую модель Phone Guy.

Адреса страниц, адрес телефонного сервера и его порты настраиваются отдельно
для каждой установки. Поэтому у разных установок адреса могут отличаться.

## 🚀 Где открыть телефон

Точные адреса нужно взять из настроек вашей установки или у её администратора.

| Что открыть | Для чего нужно | Доступ |
| --- | --- | --- |
| Браузерный телефон | Звонить из браузера | Адрес задаётся настройками; для внешнего доступа нужен вход владельца |
| Внутренний браузерный телефон | Звонить из браузера в частной сети | Адрес задаётся настройками; нужен VPN — защищённое подключение к частной сети |
| Панель управления | Настраивать голос для номеров и смотреть состояние телефонов | Адрес задаётся настройками; доступ через VPN |
| Страница конференции | Слушать конференцию | Адрес задаётся настройками; страница не включает микрофон |
| Обычный телефон с поддержкой интернет-звонков | Подключить аппарат к телефонному серверу | Адрес сервера и порт задаются настройками; подключение из сети вне VPN ещё не подтверждено |

## 📞 Как проходит звонок

1. Один человек звонит из браузера или с обычного интернет-телефона.
2. Программа управления звонками следит за вызовом, а телефонный сервер
   соединяет участников и передаёт звук.
3. Если для телефонного номера выбран голос Phone Guy, речь с этого телефона
   проходит через отдельную службу изменения голоса и возвращается в разговор.
4. Если во время разговора пропадает связь со службой обработки голоса, система
   пытается подключиться снова. Если это не удаётся, звонок может продолжиться
   с обычным голосом без обработки.

Этот механизм помогает при сбое связи именно со службой обработки голоса. Он не
исправляет плохой мобильный сигнал или все возможные потери звука в сети.

## 🧩 Из чего состоит проект

| Часть | Простое объяснение |
| --- | --- |
| Браузерный телефон | Страница, из которой можно звонить и принимать звонки |
| Панель управления | Страница для настройки телефонных номеров и голосов |
| Go-сервис | Принимает команды для звонков и просит Asterisk соединить или разъединить телефоны |
| Asterisk | Телефонный сервер, который соединяет телефоны и передаёт звук между ними |
| Служба обработки голоса (`rvc_service/`) | Меняет голос по модели Phone Guy; работает отдельно от телефонного сервера |
| Coturn | Помогает передать звук, когда устройства не могут соединиться напрямую |
| Caddy | Принимает защищённые обращения к сайту и направляет их нужным службам |
| Docker и Terraform | Инструменты для запуска служб и настройки серверной инфраструктуры |

## 🛠️ Какие технологии используются

- **Go** — программа, которая управляет звонками.
- **Asterisk и SIP** — телефонный сервер и способ подключения интернет-телефонов.
- **React и TypeScript** — инструменты, на которых сделаны страницы в браузере.
- **WebRTC** — технология для передачи звука в браузерном звонке.
- **Python и FastAPI** — инструменты, на которых работает служба обработки голоса.
- **RVC** — технология изменения голоса; в этом проекте используется модель Phone Guy.
- **Docker и Terraform** — инструменты для запуска служб и настройки серверов.

## 🗂️ Где искать код

| Путь | Что там находится |
| --- | --- |
| `cmd/voice-web/`, `internal/` | Go-сервис: звонки, телефонная книга, панель управления и связь с Asterisk |
| `admin-ui/src/phone/` | Браузерный телефон |
| `admin-ui/src/` | Панель управления |
| `conference/asterisk/` | Настройки телефонного сервера и конференции |
| `web/conference/`, `web/`, `web/live/` | Страницы для конференции и работы со звуком в браузере |
| `rvc_service/` | Служба, которая меняет голос |
| `deploy/`, `infra/terraform/` | Файлы для запуска служб и настройки серверов |
| `tests/` | Автоматические проверки кода |
| `docs/` | Инструкции, описание текущей установки и результаты приёмки звонков |

## 🧑‍💻 Если вы меняете код

Перед началом посмотрите [состояние установки](docs/LIVE_STATUS.md) и
[заметки для разработчика](docs/HANDOFF.md). В них описаны текущая версия,
особенности запуска и известные ограничения.

Из корневой папки проекта можно выполнить основные проверки:

```bash
# Проверить Go-сервис
go test ./...

# Перейти к браузерной части, установить её зависимости и выполнить проверки
cd admin-ui
npm ci
npm test -- --run
npm run build
```
